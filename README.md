# MBS Budget Calculator

Interactive budget calculator for Munich Business Speakers (Toastmasters). Models membership fees, Toastmasters pass-through dues, venue costs, and other expenses — with break-even analysis.

**Live:** https://jonasdaugalas.github.io/MBS-Budget-Calculator/

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start dev server |
| `npm run build` | Production build (single HTML file) |
| `npm run test` | Run budget calculator tests |
| `npm run lint` | Typecheck |

## GitHub Pages
